# JARVIS (Stage 1)

Native Android app (Kotlin + Jetpack Compose) for Android 8+ (built for Android 13).
Stage 1 contains the project, the dark-blue interface and a settings screen.
Voice, phone control and the other features come in later stages.
See docs/STATUS.md for honest progress and docs/BUILD_ON_PHONE.md to build the APK from your phone.
